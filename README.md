# AstroWorldMc.js

A simple, lightweight wrapper for the [AstroWorldMC API](https://api.astroworldmc.com/).

## What it does
AstroWorldMc.js allows you to interact with the AstroWorldMC External API (v1.0) through simple, clean, and fully typed functions.
The package provides convenient functions for accessing the API's routes, along with TypeScript typings for the returned data.

## Installation
Install the package using npm:
```bash
npm install astroworldmc.js
```

## Usage
You can find usage examples in the `/examples` directory.
You can also read the source code to learn more about the available functions and how they work.

## Tests
Run all tests with `npm test`, or only unit tests with `npm run test:unit`
